# SiteClone

SiteClone 是一款使用 Go 和 [MyGo](https://github.com/egoist/mygo) 开发的 Windows 桌面网站静态内容下载工具。输入 HTTP(S) 网址后，它会按设定的范围抓取页面与静态资源，整理到本地目录，并将可识别的页面和 CSS 资源引用改写为本地路径，便于预览与整理。

它适合保存有权访问和复制的站点前端页面，**不是动态网站、接口或服务端业务的完整镜像工具**。

## 功能

- **范围控制**：自动从输入网址生成根域名通配规则，也可以手动填写多个域名；支持限定/排除路径、最大深度与页面数量。
- **可选语言分站过滤**：识别路径首级的 `/en/`、`/fr/` 等明确语言目录。开启后保留起始网址所属语言；若起始网址不带语言目录，则跳过这些语言分站页面。普通路径与静态资源不因该规则直接被过滤。
- **分类保存与引用改写**：页面保存于任务目录根部，JS、CSS、图片、字体等可按类型配置保存目录；改写可识别的 HTML 和 CSS 引用。
- **文件去重**：尽量保留资源原始文件名；同名同内容复用已有文件，不同内容的路径冲突添加区分后缀。
- **下载策略**：可设置并发数、请求间隔、超时、失败重试、资源数量、单文件大小与总下载量上限，并可选择是否下载跨域静态资源。
- **任务恢复**：取消或部分失败的任务可从历史记录续传；也可对已有文件做校验修复。任务目录内的 `.siteclone` 保存恢复状态。
- **查看结果**：显示实时进度、速度、日志与任务历史；支持本地预览、定位目录和导出 ZIP。
- **请求设置**：支持 User-Agent 预设、来源网址、手动 Cookie，以及通过独立 Chrome/Edge 会话导入目标站点 Cookie 与 User-Agent；Cookie 不写入配置、历史或续传状态。
- **编码转换**：可保持原编码，或按已识别的编码将 HTML/CSS 转换为 UTF-8。

## 环境要求

- Windows x64。
- 从源码构建需要 Go **1.27.1 或更新版本**、PowerShell，以及首次获取依赖时的网络连接。
- 仅“从浏览器导入”功能需要本机安装 Google Chrome 或 Microsoft Edge；手动填写网址并下载不依赖该功能。

项目依赖版本以 [`go.mod`](go.mod) 为准。构建脚本会生成图标、运行格式化/测试/静态检查，然后构建 Windows GUI 程序。

## 构建与运行

在项目根目录的 PowerShell 中执行：

```powershell
.\build.ps1
.\SiteClone.exe
```

也可以在构建后直接启动：

```powershell
.\build.ps1 -Run
```

可选参数：

```powershell
.\build.ps1 -Offline                 # 已缓存依赖且 Windows 图标资源是最新版本时使用
.\build.ps1 -GoExe 'C:\path\to\go.exe'  # 指定 Go 编译器
```

`-Offline` 不会在线更新 Windows 图标资源；若资源缺失或已过期，需要先运行一次普通构建。默认输出程序为项目根目录的 `SiteClone.exe`。构建脚本目标平台固定为 Windows amd64。

单独运行测试与静态检查：

```powershell
go test ./... -count=1 -timeout=90s
go vet ./...
```

## 使用方法

1. 打开程序，在“新建任务”中填写完整的 HTTP(S) 下载网址。限定域名默认随网址自动识别，也可以手动输入多个域名；限定/排除路径采用路径前缀规则。
2. 选择保存目录，按需开启语言分站过滤，调整最大深度、最大页数、下载超时和编码转换。默认保存目录是 **程序所在目录下的 `downloads`**；默认最大页数为 **500**。
3. 在“文件路径”中调整静态资源分类目录；在“请求设置”中调整并发、重试、下载限制、User-Agent、Referer 或 Cookie。
4. 点击“开始下载”，到“下载进度”查看进度、速度与日志。完成后可预览、打开目录或导出 ZIP；未完成任务可在“任务历史”中续传或校验修复。

每次新任务会在保存目录中创建以目标网址域名命名的独立文件夹；如果同名目录已存在，会追加序号，不覆盖旧任务。输出目录中的 `result.json` 记录任务结果，`.siteclone` 保存续传状态。ZIP 导出不包含 `.siteclone`。

```text

  siteclone/       MyGo 桌面界面、任务交互和浏览器导入
    assets/        图标源文件与应用图标
  iconbuild/       图标生成工具
internal/
  clone/           下载引擎、配置、编码、历史、状态与预览

```

## 已知限制与安全提示

- 下载引擎通过 HTTP GET 获取前端内容，**不执行 JavaScript**；JavaScript 动态发现的资源、接口交互、ES 模块依赖、Service Worker 和服务端功能可能无法离线使用。并非所有站点都能完整还原。
- 页面中的脚本在本地预览时仍可能联网。仅预览可信站点，不要在克隆页输入真实账号或敏感信息；预览前程序会显示安全提示。
- Cookie 仅在当前运行期间保存在内存中，并仅向起始网址同源的请求发送。需要登录的站点续传时须重新填写或导入 Cookie。浏览器导入使用独立会话，不读取日常浏览器配置。
- 下载结果可能包含目标站点的版权内容或个人信息。仅在有权复制的范围内使用，遵守目标站点的访问规则；分享或上传结果前请先检查内容。
